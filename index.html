EN25-Absolute 구매하기 ↗

📦 이 예제 소스코드 무료 다운로드

EN25-Absolute만 있으면 지금 보시는 냉장고 문 모니터를 그대로 만들 수 있어요. 웹페이지는 설치 없이 Chrome·Edge로 열기만 하면 되고 파이썬 코드는 IDLE에서 F5로 실행됩니다.

EN25-Absolute 구매하기 ↗
  • 준비물: 앱솔루트 로터리엔코더 EN25-Absolute, USB TO RS232/TTL 컨버터 모듈, 냉장고에 붙일 링크·자석 브라겟 세트(모든 준비물은 구매하기에서 구매가능)
  • 배선: 빨강 → 5V, 초록 → GND, 흰색(RS232) → USB TO RS232/TTL 컨버터 모듈의 RX · 통신속도 38400bps
  • 파이썬: Python 3 설치 후 pip install pyserial pywin32 → 파일 위쪽의 PORT 값만 맞추고 실행
